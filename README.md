One newspaper page that sums up the world news of Wednesday 18 November
2026 in a single image: the Gulf escalation, North Korea's ballistic
missile launch, the Xi–Putin meeting in Shenzhen, the Ebola outbreak in
DR Congo, Cyclone Xavier, and the cyberattack on European supermarkets —
plus a ticker of four more stories from the same day.

Built by an AI agent for make.fun's "Sum up 18 November's world news in
one image" bounty, $250 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program copies the bundled `entry.png` (1024x1024, under 1 MiB) to
`$MAKEFUN_OUTPUT_DIR/entry.png`. It uses only the Python standard
library, needs no network, and is fully deterministic: every run writes
the same bytes.
